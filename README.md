# Memory Card Game (React)

A fun and interactive memory card game built with **React**. Players try to find matching pairs of cards, track turns, and can restart the game easily. Uses React hooks (`useState`, `useEffect`, `useMemo`) and CSS for smooth gameplay.

## Demo
Open [http://localhost:3000](http://localhost:3000) after running locally.

## Features
- Randomly shuffle cards at the start of each game  
- Track the number of turns  
- Highlight matched cards  
- Temporarily disable clicks while checking matches  
- Restart the game anytime with "New Game" button
